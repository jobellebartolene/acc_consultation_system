Security Policy

Passwords are hashed with Werkzeug's PBKDF2 implementation and never stored in plain text.

Accounts lock automatically for {{ config.LOCKOUT_MINUTES if config else 15 }} minutes after {{ config.MAX_LOGIN_ATTEMPTS if config else 5 }} consecutive failed login attempts.

Sessions expire after 8 hours of inactivity and use HttpOnly, SameSite=Lax cookies.

Role Permissions

  • Super Admin — full access: manage all accounts, all consultations, and system settings.
  • Medical Expert — manage only consultations assigned to them; add clinical notes and diagnoses.
  • Student — read-only access to consultations they are assigned to observe.
